# Modern C++

## Compile

Run the following command from the directory containing the `.cpp` file:

```bash
g++ [FILENAME].cpp -o ../build/[FILENAME]
```

> This command assumes the source file is inside a subdirectory, such as intro/ or oop/, and that the build/ directory exists in the project root.

## Run

If you are inside a code directory, run:

```bash
../build/[FILENAME]
```

If you are in the project root, run:

```bash
./build/[FILENAME]
```
